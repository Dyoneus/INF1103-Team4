# INF1103-Team4

Hi guys, please do a branch before you start:

1. Pull the latest changes:
   git pull

2. Create and switch to your own branch:
   git checkout -b <your_section> #For example if mine, git checkout -b ai_manager

3. Check that you are on the correct branch:
   git branch

4. Work on your assigned section and commit your changes normally.

5. Push your branch:
   git push -u origin <your_section>

6. When your work is ready, open a Pull Request on GitHub for review before merging into main.
